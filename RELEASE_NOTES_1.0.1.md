# TouchKio Card 1.0.1

## Geändert

- Die Laufzeit wählt die Einheit automatisch: Minuten, Stunden, Tage und ab 7 Tagen Wochen (z. B. „5 Std 12 Min“, „2 Tage 4 Std“, „3 Wochen 2 Tage“).
- Lizenzhinweis im Code und ausführlicherer Lizenzabschnitt in der README (AGPL-3.0-only).
- README mit Button zum automatischen Hinzufügen in HACS und aktualisiertem Screenshot.

## Entfernt

- Die Box **Seiten-Zoom** und die Option `zoom_entity`. Eine bestehende Angabe in der Konfiguration wird ignoriert; die Karte funktioniert ohne Anpassung weiter.

## Update

Über HACS aktualisieren und den Browser bzw. die Home-Assistant-App vollständig neu laden. Die Konfiguration muss nicht geändert werden.
